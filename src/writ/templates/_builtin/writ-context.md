# writ CLI

`writ` provides instruction quality scoring (`writ lint`), security review (`writ lint --prompt --security`), plan review (`writ plan review`), documentation health (`writ docs check/update`), agent-to-agent communication (`writ chat/connect`), and cross-device instruction sync (`writ save/sync`).
